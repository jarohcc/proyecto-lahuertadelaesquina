# proyecto-lahuertadelaesquina

Este será el repositorio que se utilizará para guardar todo el material que utilicemos para avanzar en el proyecto de nuestra empresa.

# Descripción

Una tienda que vende verduras cultivadas en una huerta del pueblo o cercana a este, cuyo principal objetivo es ser una tienda de confianza en la que se sepa que todos los productos utilizados, tanto para la venta como para producir las verduras, son sostenibles y locales, poniendo siempre el bienestar del medio ambiente en primer lugar. También queremos que sea un espacio al que las personas mayores puedan acudir con total confianza y sin sufrir sobreinformación.
